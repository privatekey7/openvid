> ## Об этом форке
>
> Это **поддерживаемый сообществом русский форк** проекта [openvid от @CristianOlivera1](https://github.com/CristianOlivera1/openvid).
>
> **Все авторские права и заслуги за OpenVid принадлежат его оригинальному автору — [Cristian Olivera](https://github.com/CristianOlivera1).** Дизайн, архитектура и основной функционал — полностью его работа. Если вам нужна официальная версия со всеми возможностями (облачная синхронизация, авторизация и т.д.) — используйте [оригинальный репозиторий](https://github.com/CristianOlivera1/openvid) и демо на [openvid.dev](https://openvid.dev).
>
> ### Что отличается в этом форке
> - Добавлена русская локализация (`messages/ru.json`)
> - Ключи API провайдеров перенесены на сервер (`UNSPLASH_ACCESS_KEY` вместо `NEXT_PUBLIC_*`) — больше не утекают в клиентский бандл
> - Удалена интеграция с Supabase для полностью локального self-hosted использования (без авторизации и облачного хранилища)
> - Обновлены зависимости — закрыты известные уязвимости
>
> Поддерживается [@privatekey7](https://github.com/privatekey7). Полная атрибуция — в файлах [`AUTHORS.md`](./AUTHORS.md) и [`NOTICE`](./NOTICE).
>

## Возможности

### Видео на входе
- **Запись экрана** — прямо в браузере, без установки чего-либо
- **Загрузка своего видео** — MP4, WebM, QuickTime, MKV
- **Drag & drop** — быстрая загрузка файлов

---

### Создание мокапов
- **Мокапы поверх изображений**
- **3D-трансформации**
- **Маскирование изображений (Mask Image)** — продвинутые вырезы
- Настройка масштаба, поворота, перспективы и позиции

---

### Визуальная настройка

**Фоны**
- 100+ готовых фонов
- Свои изображения или Unsplash
- Сплошные цвета и градиенты
- Эффект размытия (0–100%)

**Эффекты**
- Динамические отступы (padding)
- Скруглённые углы
- Тени
- Поворот и позиционирование видео

---

### Канвас и элементы
- **Фигуры** — прямоугольники, круги, треугольники
- **Текст** — кастомные шрифты, цвета и размеры
- **SVG** — импорт векторной графики
- **Изображения** — оверлеи в форматах PNG, JPG, WebP
- **Слои** — управление глубиной (над или под видео)

---

### Мокапы устройств
Добавьте контекст к демо с помощью профессиональных рамок:
- Safari (macOS)
- Chrome
- Arc
- Samsung

---

### Зум
- Зум in/out в конкретных моментах таймлайна
- Управление скоростью и easing-кривой
- **3D-движение камеры** — наклон и динамическое вращение по точкам интереса
- **Настраиваемая перспектива** — полный контроль над осями X и Y для имитации глубины

---

### Аудио
- Поддержка нескольких треков
- Регулировка громкости каждого трека и общей
- Авто-обрезка по длительности видео
- Включение/выключение оригинального звука видео

---

### Экспорт

**Качество**
- 4K (3840×2160) @ 30fps
- 2K (2560×1440) @ 30fps
- 1080p (1920×1080) @ 30fps
- 720p (1280×720) @ 30fps
- 480p (720×480) @ 24fps

**Форматы**
- MP4 (H.264)
- WebM (VP9 с поддержкой прозрачного фона)
- GIF
- PNG, WEBP, JPG, AVIF

---

## Технологии

**Обработка видео**
- FFmpeg.wasm — рендеринг полностью в браузере
- Canvas API — превью
- MediaBunny — оптимизированный пайплайн видео
- Three.js — 3D-эффекты
- HTML to Image — экспорт мокапов

**Хранилище**
- IndexedDB — локально записанные видео
- LocalStorage — пользовательские настройки

**UI/UX**
- Radix UI — доступные компоненты
- Framer Motion — анимации
- Tailwind CSS 4 — стилизация

---

## Быстрый старт
```bash
# Установить зависимости
pnpm install

# Настроить окружение (опционально — нужно только для интеграций с фото-провайдерами)
cp .env.example .env

# Запустить dev-сервер
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000)
